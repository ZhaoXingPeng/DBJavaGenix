# 模板依赖动态引入方案

## 问题描述

当前代码生成模板中使用了一些特定的依赖，如：
- `org.springframework.data.domain.Page` 等Spring Data JPA相关类
- `javax.annotation.Resource` 等Javax注解
- `io.swagger.annotations.*` 等Swagger 2.x注解

但用户项目可能存在以下情况：
1. 用户项目使用较老的技术栈（Javax + JPA + Swagger 2.x）
2. 用户项目使用较新的技术栈（Jakarta + MyBatis + SpringDoc OpenAPI 3.0）
3. 用户项目没有指定特定依赖，应使用默认的现代化技术栈

## 解决方案

### 1. 动态依赖检测

通过 [DependencyManager](file:///c%3A/project/ai/task/coder_prompt/DBJavaGenix/src/dbjavagenix/utils/dependency_manager.py#L26-L203) 和 [PomAnalyzer](file:///c%3A/project/ai/task/coder_prompt/DBJavaGenix/src/dbjavagenix/utils/pom_analyzer.py#L33-L604) 分析用户项目的依赖情况：

- 检测是否存在 `javax.annotation:javax.annotation-api` 或 `jakarta.annotation:jakarta.annotation-api`
- 检测是否存在 `org.springframework.data:spring-data-commons` 或其他Spring Data依赖
- 检测是否存在 `io.swagger:swagger-annotations` 或 `org.springdoc:springdoc-openapi-*`

### 2. 模板条件化

根据不同依赖情况，动态调整模板内容：

#### 路径一：用户使用较老技术栈（Javax + JPA + Swagger 2.x）
- 保留现有的导入语句：
  ```java
  import org.springframework.data.domain.Page;
  import org.springframework.data.domain.PageImpl;
  import org.springframework.data.domain.PageRequest;
  import javax.annotation.Resource;
  import io.swagger.annotations.Api;
  import io.swagger.annotations.ApiOperation;
  import io.swagger.annotations.ApiParam;
  ```
- 保留现有的注解使用

#### 路径二：用户使用较新技术栈（Jakarta + MyBatis + SpringDoc OpenAPI 3.0）
- 使用替代的分页实现（如MyBatis分页插件）
- 使用 `jakarta.annotation.Resource` 替代 `javax.annotation.Resource`
- 使用SpringDoc注解替代Swagger注解

#### 路径三：用户未指定依赖（默认现代化技术栈）
- 默认使用Jakarta技术栈
- 使用MyBatis分页替代Spring Data分页
- 使用SpringDoc OpenAPI 3.0替代Swagger 2.x

### 3. 模板变量控制

在模板上下文构建器中添加以下变量：

```python
# 依赖相关标志
"hasJavax": False,           # 是否使用Javax注解
"hasJakarta": True,          # 是否使用Jakarta注解
"hasSpringData": False,      # 是否使用Spring Data
"hasMyBatis": True,          # 是否使用MyBatis
"hasSwagger2": False,        # 是否使用Swagger 2.x
"hasSpringDoc": True,        # 是否使用SpringDoc OpenAPI 3.0
"useModernStack": True,      # 是否使用现代化技术栈
```

### 4. 模板结构调整

#### ServiceImpl模板调整

```mustache
{{#hasSpringData}}
import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageImpl;
import org.springframework.data.domain.PageRequest;
{{/hasSpringData}}
{{^hasSpringData}}
// 使用MyBatis分页或其他分页实现
{{/hasSpringData}}

{{#hasJavax}}
import javax.annotation.Resource;
{{/hasJavax}}
{{#hasJakarta}}
import jakarta.annotation.Resource;
{{/hasJakarta}}

public class {{className}}ServiceImpl implements {{className}}Service {
    
    @Resource
    private {{className}}Dao {{entityNameLowerCase}}Dao;
    
    {{#hasSpringData}}
    @Override
    public Page<{{className}}> queryByPage({{className}} {{entityNameLowerCase}}, PageRequest pageRequest) {
        long total = this.{{entityNameLowerCase}}Dao.count({{entityNameLowerCase}});
        return new PageImpl<>(this.{{entityNameLowerCase}}Dao.queryAllByLimit({{entityNameLowerCase}}, pageRequest), pageRequest, total);
    }
    {{/hasSpringData}}
    
    {{^hasSpringData}}
    // 使用MyBatis分页实现
    {{/hasSpringData}}
}
```
