# 2025-11-17: MCP 一周年生态总览

## 数字 (Anthropic 官方)
- 2024-11 MCP 发布,初期 ~100 个 server
- 2025-04 增长到 8M+ downloads
- 2025-09 推出 MCP Registry (类似 npm registry for MCP)
- 2025-11 Registry 收录 2000+ servers

## 关键时间点
- 2024-11-25: MCP spec v1 (SSE transport, no OAuth)
- 2025-03-26: spec v2 (OAuth, Streamable HTTP, tool annotations)
- 2025-06-18: spec v3 (elicitation, sampling, structured outputs)
- 2025-09: MCP Registry
- 2025-10: OpenAI Agents SDK 正式支持 MCP (March 25 已宣布)
