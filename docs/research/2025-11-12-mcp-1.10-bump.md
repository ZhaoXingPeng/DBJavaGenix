# 2025-11-12: MCP SDK 1.0 → 1.10

## 变更
- 完整支持 2025-06-18 spec 的 elicitation / sampling
- `tools/list` 响应支持 annotations (readOnly / destructive)
- `_meta` 字段从 reserved 转为正式可用

## 我们的影响
- requirements.txt: mcp>=1.0.0 → mcp>=1.10.0
- 现有 db_query_tables / db_codegen_generate 工具不受影响 (向后兼容)

## 验证
跑了 v0.1 全套测试,无回归。

## 后续
- v0.2 ai_* 工具开发时直接用 1.10 的 _meta 字段携带 MCP App 数据
