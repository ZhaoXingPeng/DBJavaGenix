# 包命名策略

## 概述
本文档说明DBJavaGenix项目在不同平台上的包命名策略。

## 当前命名情况

### Python包 (PyPI)
- **包名**: `dbjavagenix`
- **配置文件**: [pyproject.toml](file:///C:/project/ai/task/coder_prompt/DBJavaGenix/pyproject.toml)
- **安装命令**: 
  ```bash
  pip install dbjavagenix
  # 或
  uv add dbjavagenix
  ```

### npm包
- **包名**: `dbjavagenix-mcp-server`
- **配置文件**: [package.json](file:///C:/project/ai/task/coder_prompt/DBJavaGenix/package.json)
- **安装命令**:
  ```bash
  npm install dbjavagenix-mcp-server
  ```

## 命名策略分析

### 1. Python包命名 (`dbjavagenix`)
**优势**:
- 简洁明了，与项目名称一致
- 符合Python社区的命名习惯
- 易于记忆和使用

**劣势**:
- 未明确表明是MCP服务器

### 2. npm包命名 (`dbjavagenix-mcp-server`)
**优势**:
- 明确表明这是MCP服务器
- 避免与同名的其他npm包冲突
- 便于用户搜索和识别

**劣势**:
- 名称较长
- 与Python包名称不一致

## 建议方案

### 方案一：保持现状（推荐）
- **Python包**: `dbjavagenix` (保持简洁)
- **npm包**: `dbjavagenix-mcp-server` (明确功能)

**适用场景**:
- 希望在npm上明确标识MCP服务器功能
- 不担心跨平台命名不一致

### 方案二：统一命名
- **Python包**: `dbjavagenix`
- **npm包**: `dbjavagenix`

**优势**:
- 跨平台命名一致
- 简洁易记

**劣势**:
- npm包名可能与其他包冲突
- 未明确表明MCP服务器功能

## 使用建议

### 对于用户
```bash
# Python环境安装
pip install dbjavagenix

# Node.js环境安装
npm install dbjavagenix-mcp-server
```

### 对于开发者
1. 在文档中明确说明不同平台的包名差异
2. 提供清晰的安装指南
3. 在README中说明命名策略的原因

## 结论

推荐使用**方案一**（保持现状），因为：
1. npm包名的明确性对于用户识别功能很重要
2. Python包的简洁性符合社区习惯
3. 两种命名策略各有优势，适应不同平台的特点
