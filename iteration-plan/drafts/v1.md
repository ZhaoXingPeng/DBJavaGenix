# DBJavaGenix v0.2 重构方案 - 草稿 v1

> 2025-12-29 起草。基于 2025-09 ~ 2025-12 4 个月的 MCP / Skills / Agent SDK 演进研究。

## 目标
1. 把 v0.1 的"大工具一键生成"改造为"Skill 编排 + 原子工具"
2. 引入 MCP v3 的 _meta / 渐进发现
3. 配套 4 个 MCP Apps 组件(ER 图 / 依赖仪表盘 / code-diff / 包结构树)
4. 加强可观测性(metrics + structured logs)
5. 完整的 ADR 和 demo 故事

## Phase 拆分(初步)
1. Phase 1: 基础升级 + CI + Docker
2. Phase 2: Skills + Atomic Tools + Token 优化
3. Phase 3: MCP Apps 四组件
4. Phase 4: AI 工具系列(规则优先)
5. Phase 5: 可观测性 + 生产就绪
6. Phase 6: 文档 / ADR / Demo

## 时间预估
6 阶段 × 3-5 天 = 3 周左右。

## 风险点
- v0.1 模板系统的兼容性(改原子工具可能破坏现有调用方)
- CI 一些 silent-fail 测试需要先修
